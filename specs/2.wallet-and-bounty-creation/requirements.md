# wallet-and-bounty-creation — 需求规格

## 概述

实现钱包连接、Monad 网络校验/切换，以及创建悬赏的表单与链上交易流程，覆盖 PRD 用户流程 §9.1。

## 项目信息

- 项目名: bounty-mint
- 架构类型: Web3 dApp（单仓库：前端 + API 编排器 + Solidity 合约，无数据库）

## 需求版本

| 日期 | 版本 | 说明 |
| ---- | ---- | ---- |
| 2026-08-14 | v1 | 初始需求 |

## 用户故事

- 作为悬赏发布者，我希望连接钱包并看到地址和 MON 余额，以便确认可以支付奖金。
- 作为悬赏发布者，我希望在错误网络时能一键切换到 Monad，以便顺利发起交易。
- 作为悬赏发布者，我希望输入创意想法并锁定奖金，以便让 Creator Agent 围绕需求创作。

## 功能需求

1. [F-001] 使用 RainbowKit + wagmi 提供钱包连接入口，连接后展示地址与 MON 余额。
2. [F-002] 校验当前网络是否为目标 Monad 网络，非目标网络时展示 `Switch Network` 并调用钱包切链。
3. [F-003] 提供 Brief 输入框（含默认 Brief，见 PRD §7.1）、奖金金额输入、截止时间、授权声明勾选。
4. [F-004] 点击 `Launch Bounty` 调用 `createBounty` 合约写入，展示交易 pending/success/error 状态。
5. [F-005] 交易成功后页面进入 `CREATING` 状态；用户拒绝交易时保留已输入内容，状态回到可编辑（PRD §17）。

## 非功能需求

- 性能: 钱包连接与余额读取应在正常网络下 2 秒内完成首次渲染反馈（loading 态即可，非强制指标）。
- 安全: 私钥/助记词不经过应用后端；所有签名操作走钱包扩展/APP。
- 兼容性: 覆盖主流浏览器钱包（MetaMask 等 RainbowKit 支持的连接器），移动端保证基本可用。

## 验收标准

- [ ] [AC-001] 未连接钱包时 `Launch Bounty` 按钮禁用并提示连接钱包。
- [ ] [AC-002] 连接钱包后正确显示地址与 MON 余额。
- [ ] [AC-003] 非 Monad 网络下点击 `Switch Network` 能成功切链（或在钱包不支持自动添加网络时给出清晰指引）。
- [ ] [AC-004] 余额不足时禁止发起交易并展示所需金额。
- [ ] [AC-005] 创建交易 pending/success/error 三态在 UI 上均有明确反馈，成功后展示交易哈希链接。
- [ ] [AC-006] 用户在钱包中拒绝交易后，表单输入内容不丢失。
