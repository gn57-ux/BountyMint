# deploy-and-demo-readiness — 需求规格

## 概述

完成桌面 Web 动效收尾、Vercel 公网部署、桌面浏览器检查，以及 README 与演示材料整理，覆盖 PRD §11.2、§21 阶段 D/E、§22 发布检查清单。

## 项目信息

- 项目名: bounty-mint
- 架构类型: Web3 dApp（单仓库：前端 + API 编排器 + Solidity 合约，无数据库）

## 用户故事

- 作为评委，我希望在公网无痕窗口打开演示地址即可体验完整流程，无需阅读 README。
- 作为团队成员，我希望有清晰的 README 和演示材料，以便顺利完成比赛提交。

## 功能需求

1. [F-001] 实现 Reveal 翻转、奖金资金流、NFT 铸造三处关键动效，且支持 `prefers-reduced-motion`。
2. [F-002] 完成 Vercel 部署配置，包含所有环境变量（OpenAI Key、Pinata Key、executor 私钥、Monad RPC 等）。
3. [F-003] 使用 Monad Testnet（Chain ID `10143`、RPC `https://testnet-rpc.monad.xyz/`、Explorer `https://testnet.monadexplorer.com/`）部署合约并接入前端；若比赛官方临时指定其他 Monad 网络，以最新规则替换。
4. [F-004] 完成桌面 Chrome 无痕窗口的主流程与常用分辨率检查；移动端明确不在本次范围内。
5. [F-005] 编写 README（合约地址、公网 URL、部署说明）、准备项目截图、60-90 秒演示脚本材料。
6. [F-006] 首页与演示文案统一定位为“运行在 Monad 上的 AI 创作悬赏协议”，完整演示 `锁定 MON → 三 Commit → 三 Reveal → 选胜者 → 支付 MON + 铸造 NFT`，并在页面直接呈现链上证据。

## 非功能需求

- 性能: 动效不得阻塞任何链上交易或表单操作的可用性。
- 安全: 部署环境变量通过 Vercel 平台配置，不写入代码仓库；`.env.example` 只含变量名。
- 兼容性: 公网 URL 需在无痕窗口下正常访问并完成完整流程。

## 验收标准

- [ ] [AC-001] 三处关键动效正常播放，且在系统开启"减少动态效果"时自动降级为无动画或简化过渡。
- [ ] [AC-002] 公网 Vercel URL 可访问，且从创建悬赏到铸造成功的完整链路可运行。
- [ ] [AC-003] 合约部署在真实 Monad 网络（非占位配置），地址写入 README。
- [ ] [AC-004] 桌面 Chrome 无痕窗口可完成连接钱包、创建悬赏、查看结果的完整流程。
- [ ] [AC-005] 连续完成至少五次端到端演示，其中至少一次触发图片缓存回退路径。
- [ ] [AC-006] 仓库不包含私钥、API Key 等敏感信息。
- [ ] [AC-007] README 和 Demo 页面提供合约地址、至少一笔创建交易、Commit/Reveal 交易与 Award/NFT 交易的可点击 Explorer 证据。
